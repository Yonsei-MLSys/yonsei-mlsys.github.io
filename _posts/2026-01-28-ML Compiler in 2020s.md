<h5>
    Kiung Jung - ASO Lab, CS, Yonsei University
</h5>

This presentation explores the trends and core concepts of ML compilers in the 2020s, emphasizing that compiling deep learning models is necessary for efficient execution on GPUs. 
The talk details the kernel invocation process using a Step-by-Step GEMM example and compares the roles of the Host (CPU) compiler in kernel programming with the Device (GPU) compiler in kernel management, including scheduling and fusion. 
Modern compiler technologies covered include torch.compile and TensorRT, highlighting the difficulty associated with optimizing kernel fusion. 
Finally, the discussion leverages background technologies such as IR, CUDA UVM, CXL, and Intel DSA to explore data offloading solutions for cost-efficient inference and memory shortage issues.
